J.P. Morgan – Software Engineering Virtual Experience (Forage)

This repository contains my solutions for the **J.P. Morgan Software Engineering Virtual Experience** on [Forage](https://www.theforage.com/).  
The project simulates real-world tasks performed by J.P. Morgan software engineers, focusing on financial data visualization and code quality improvements.

Overview

The virtual experience includes multiple tasks designed to build skills in:
- Financial data processing
- Front-end and back-end integration
- Data visualization using web technologies
- Debugging, refactoring, and working with APIs

Project Structure
forage-midas/
├── task1/ # Interface with J.P. Morgan's data feed (Python)

Tasks Summary
Task 1 – Interface with a Data Feed**
- Set up a local environment.
- Read and process real-time stock price data.
- Output formatted price data.
Task 2 – Use the Data Visualization Tool**
- Use J.P. Morgan’s visualization framework.
- Display live data as a graph.
- Update the graph dynamically with new data.
Task 3 – Fix Broken Data Feed**
- Debug existing code.
- Ensure accurate data rendering on the dashboard.
Task 4 – Improve Code Quality**
- Refactor existing code.
- Add docstrings and improve readability.
Task 5 – Testing and Verification**
- Implement and run automated tests.
- Ensure proper application context loading.
